## Learning Path

A practical progression is:

1. Begin with **Momentum Fingerprint** to develop application reconnaissance habits.
2. Continue with the hidden-path and website-content enumeration challenges.
3. Study **Secret Strings** and the JavaScript-focused labs to understand client-side exposure.
4. Move into source-analysis challenges such as **Source Sleuth Momentum**.
5. Explore cookie and credential-focused challenges.
6. Finish with the cipher and CryptoJS challenges to strengthen cryptographic analysis skills.

## How to Use the Labs

1. Choose a challenge from the collection.
2. Read its instructions and identify the main security concept.
3. Work only within the authorized lab environment.
4. Observe application behavior and document relevant findings.
5. Analyze source code, cookies, scripts, paths, or cryptographic material when the challenge calls for it.
6. Record your methodology and the security principle demonstrated.
7. Consider how the underlying issue could be prevented or detected in a real application.

Use these exercises only against systems and environments where you have explicit authorization.
